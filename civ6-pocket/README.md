# 文明 6 · 口袋百科

由 **Applespriter** 制作的《文明 VI》速查站。页面顶部和底部带有制作署名；本站使用“风云变幻”规则集，并包含文明百科该规则集列出的 DLC 条目。完整项目说明见上一级 [README](../README.md)。

- 科技树：77 个科技条目，展示研究前置、尤里卡条件与解锁内容。
- 文化树：61 个市政条目，展示市政前置、鼓舞条件与解锁内容。
- 奇观：53 座，展示效果、产出、解锁项目、建造地形与邻接要求。
- 地图：13 种地形、17 种地貌、34 处自然奇观与 55 种资源。资源展示自然出现位置、改良方式与产出，并能与地形、地貌和改良设施互相跳转。
- 其他解锁：519 个单位、建筑、区域、改良设施与道路、政体和政策卡条目，可按类别和所属分类筛选。科技树和文化树中的解锁可直接打开本地详情。
- 领袖：77 个领袖条目，附领袖能力与对应文明能力，可按文明筛选。
- 城邦：48 个，按工业、军事、科技、贸易、文化和宗教类型筛选，展示使者奖励、宗主国加成与相关专属解锁。
- 伟人：212 位，按类别和时代筛选，查看能力、巨作及激活说明。
- 机制：16 个常用玩法速查条目。

政策卡按军事、经济、外交和通用类型使用红、黄、绿、紫色渐变；单位、建筑等条目按升级路线或所属区域采用一致的颜色。城邦也按类型区分背景。专属单位标出所属文明，并可与对应领袖条目互相跳转。机制详情包含胜利条件和实战提示；科技、市政、奇观、地图及城邦的 358 张图标随网页一起提供，离线版也可查看。

在奇观时代、解锁所属分类、领袖文明或伟人类型与时代的筛选结果中打开条目时，保留当前筛选；跳转到筛选外的条目时，切换到目标所属的筛选条件。

数据来源：[文明百科 · 风云变幻规则集](https://www.civilopedia.net/zh-CN/gathering-storm/concepts/intro/)；图标来自其静态图片资源。站内条目与解锁关系均在本地展示，不提供外部跳转。生成的数据只保留游戏规则字段，不采集历史背景文章。数值按该站的基准花费显示，游戏速度、资料片、模式和改动会影响实际游戏结果。

伟人列表按类型、时代和名称排列，供查阅使用；同类型、同一时代的游戏出现顺序并不由列表决定。

站点为静态文件，直接用 HTTP 服务器提供 `dist/` 即可。

需要重新生成数据时：

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/build_data.py
```

只更新伟人条目时，可运行 `python3 scripts/build_data.py --great-people-only`。
只更新其他解锁条目时，可运行 `python3 scripts/build_data.py --unlocks-only`。
只更新地图、资源与城邦条目时，可运行 `python3 scripts/build_data.py --map-only`。
如需重新抓取科技、市政、奇观、地图和城邦图标，运行 `python3 scripts/fetch_icons.py`。脚本使用文明百科对应条目的图片，并将其保存到 `dist/images/`。
